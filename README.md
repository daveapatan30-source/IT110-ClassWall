IT 110 Activity: Cookies, Sessions and PostgreSQL

Project: ClassWall

A simple PHP and PostgreSQL message board where users can post messages, search messages, remember their names using cookies, and track visits using sessions.

Technologies Used:

PHP
PostgreSQL
XAMPP
pgAdmin 4
HTML 

Activity Questions

1. What is the difference between a cookie and a session?

A cookie stores information in the user's browser and can remember information across visits. A session stores information on the server and is commonly used to track a user's activity while visiting a website.

2. Where is each one stored (browser or server)?

Cookies are stored in the user's browser, while session data is stored on the server. The browser holds a session ID to identify the session.

3. Why do we use prepared statements?

Prepared statements protect the database against SQL injection attacks by separating SQL commands from user input, making database queries safer.
